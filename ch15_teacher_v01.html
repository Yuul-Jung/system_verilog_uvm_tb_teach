00개요 · 버스 거래와 레지스터 검증

제14장의 UART는 바이트 스트림을 전달했습니다. 이번 장에서는 AXI4-Lite(에이엑스아이 포 라이트, 경량 메모리 매핑 버스)를 통해 주소와 데이터를 전달하고 레지스터 값을 읽습니다. 독립된 다섯 채널의 수락, 응답 유지, 바이트 쓰기, 리셋을 검증합니다.

설계 개념 연계: 제2부 사용자 AXI IP와 주변장치(amd_soc_p2) 04.2장 03~04절 AXI 핸드셰이크·WSTRB, 10.3장 사양서 2~3절 공통 버스·레지스터 계약, 03.2장 IRQ 관련 설계. 해당 PWM 및 버튼 IP의 RTL과 이 장의 범용 어댑터·레지스터 뱅크는 동일 파일로 확인되지 않았습니다. 이 장은 기존 검증용 스냅샷 두 파일의 독립 실습이며 개념만 연계합니다.

교수용 이론 · CPU의 쓰기를 회로 상태 변화로 연결한다

AXI4-Lite는 주소로 주변장치 레지스터를 선택하는 메모리 매핑 버스입니다. 주소를 받았다는 사실, 쓸 데이터를 받았다는 사실, 저장이 반영되었다는 사실, CPU가 완료 응답을 받았다는 사실은 서로 다른 사건입니다. 다섯 채널로 분리하면 상대가 잠시 멈춰도 각 사건을 보존할 수 있습니다.

현재 DUT는 범용 검증 스냅샷 두 모듈입니다. 다른 교재의 PWM/IRQ IP와 개념은 이어지지만 동일 구현이나 최신 IP의 오류 응답 정책을 시험한 결과로 확대하지 않습니다.

module axi4lite_slave_adapter #(
    parameter integer C_S_AXI_ADDR_WIDTH = 32
)(
    input  wire                          s_axi_aclk,
    input  wire                          s_axi_aresetn,

    // AXI4-Lite Write Address Channel
    input  wire [C_S_AXI_ADDR_WIDTH-1:0] s_axi_awaddr,
    input  wire [2:0]                    s_axi_awprot,
    input  wire                          s_axi_awvalid,
    output wire                          s_axi_awready,

    // AXI4-Lite Write Data Channel
    input  wire [31:0]                   s_axi_wdata,
    input  wire [3:0]                    s_axi_wstrb,
    input  wire                          s_axi_wvalid,
    output wire                          s_axi_wready,

    // AXI4-Lite Write Response Channel
    output reg  [1:0]                    s_axi_bresp,
    output reg                           s_axi_bvalid,
    input  wire                          s_axi_bready,

    // AXI4-Lite Read Address Channel
    input  wire [C_S_AXI_ADDR_WIDTH-1:0] s_axi_araddr,
    input  wire [2:0]                    s_axi_arprot,
    input  wire                          s_axi_arvalid,
    output wire                          s_axi_arready,

    // AXI4-Lite Read Data Channel
    output reg  [31:0]                   s_axi_rdata,
    output reg  [1:0]                    s_axi_rresp,
    output reg                           s_axi_rvalid,
    input  wire                          s_axi_rready,

    // Bus-independent register access interface
    output wire                          wr_en,
    output wire [7:0]                    wr_offset,
    output wire [31:0]                   wr_data,
    output wire [3:0]                    wr_strb,

    output wire [7:0]                    rd_offset,
    input  wire [31:0]                   rd_data
);

// AXI response code used by this basic slave.
localparam [1:0] AXI_RESP_OKAY = 2'b00;

// Write Address and Write Data are independent AXI channels.
// Each channel is buffered separately until both are available.
reg                          aw_stored;
reg [C_S_AXI_ADDR_WIDTH-1:0] awaddr_stored;
reg                          w_stored;
reg [31:0]                   wdata_stored;
reg [3:0]                    wstrb_stored;

wire write_commit;

// Single-outstanding-write policy:
// Do not accept a new write while a response is pending.
assign s_axi_awready =
    s_axi_aresetn && !aw_stored && !s_axi_bvalid;

assign s_axi_wready =
    s_axi_aresetn && !w_stored && !s_axi_bvalid;

// Register-bank write occurs only after BOTH address and data
// channels have completed their independent handshakes.
assign write_commit =
    aw_stored && w_stored && !s_axi_bvalid;

assign wr_en     = write_commit;
assign wr_offset = awaddr_stored[7:0];
assign wr_data   = wdata_stored;
assign wr_strb   = wstrb_stored;

// Read side accepts one address only when no previous R response
// is waiting for the master.
assign s_axi_arready =
    s_axi_aresetn && !s_axi_rvalid;

// custom_register_bank read path is combinational.
// The address presented during AR handshake selects rd_data.
assign rd_offset = s_axi_araddr[7:0];

// AWPROT / ARPROT are not used by this educational register slave.
wire unused_prot;
assign unused_prot = ^{s_axi_awprot, s_axi_arprot};

always @(posedge s_axi_aclk) begin
    if (!s_axi_aresetn) begin
        aw_stored     <= 1'b0;
        awaddr_stored <= {C_S_AXI_ADDR_WIDTH{1'b0}};
        w_stored      <= 1'b0;
        wdata_stored  <= 32'h0000_0000;
        wstrb_stored  <= 4'b0000;
        s_axi_bresp   <= AXI_RESP_OKAY;
        s_axi_bvalid  <= 1'b0;
    end else begin
        // Capture Write Address independently.
        if (s_axi_awready && s_axi_awvalid) begin
            aw_stored     <= 1'b1;
            awaddr_stored <= s_axi_awaddr;
        end

        // Capture Write Data independently.
        if (s_axi_wready && s_axi_wvalid) begin
            w_stored     <= 1'b1;
            wdata_stored <= s_axi_wdata;
            wstrb_stored <= s_axi_wstrb;
        end

        // Once both parts exist, pulse wr_en through write_commit
        // and create the AXI B response.
        if (write_commit) begin
            aw_stored    <= 1'b0;
            w_stored     <= 1'b0;
            s_axi_bresp  <= AXI_RESP_OKAY;
            s_axi_bvalid <= 1'b1;
        end else if (s_axi_bvalid && s_axi_bready) begin
            s_axi_bvalid <= 1'b0;
        end
    end
end

always @(posedge s_axi_aclk) begin
    if (!s_axi_aresetn) begin
        s_axi_rdata  <= 32'h0000_0000;
        s_axi_rresp  <= AXI_RESP_OKAY;
        s_axi_rvalid <= 1'b0;
    end else begin
        // Capture the selected register value at AR handshake.
        if (s_axi_arready && s_axi_arvalid) begin
            s_axi_rdata  <= rd_data;
            s_axi_rresp  <= AXI_RESP_OKAY;
            s_axi_rvalid <= 1'b1;
        end else if (s_axi_rvalid && s_axi_rready) begin
            s_axi_rvalid <= 1'b0;
        end
    end
end

endmodule

module custom_register_bank (
    input  wire        clk,
    input  wire        resetn,

    // Bus-independent register access interface.
    // SoC 12 will connect this interface to AXI4-Lite.
    input  wire        wr_en,
    input  wire [7:0]  wr_offset,
    input  wire [31:0] wr_data,
    input  wire [3:0]  wr_strb,

    input  wire [7:0]  rd_offset,
    output reg  [31:0] rd_data,

    // Hardware status / event inputs
    input  wire        busy_i,
    input  wire        done_i,
    input  wire        error_i,
    input  wire        irq_done_event_i,
    input  wire        irq_error_event_i,
    input  wire [31:0] data_out_i,

    // Control outputs
    output reg         enable_o,
    output reg  [1:0]  mode_o,
    output reg         start_pulse_o,
    output reg         clear_pulse_o,
    output reg  [31:0] data_in_o,
    output reg  [1:0]  irq_status_o
);

localparam [7:0] REG_CONTROL    = 8'h00;
localparam [7:0] REG_STATUS     = 8'h04;
localparam [7:0] REG_COMMAND    = 8'h08;
localparam [7:0] REG_IRQ_STATUS = 8'h0C;
localparam [7:0] REG_DATA_IN    = 8'h10;
localparam [7:0] REG_DATA_OUT   = 8'h14;
localparam [7:0] REG_VERSION    = 8'h18;
localparam [7:0] REG_ID         = 8'h1C;

localparam [31:0] VERSION_VALUE = 32'h0001_0000;
localparam [31:0] ID_VALUE      = 32'h524D_4150; // ASCII "RMAP"

integer byte_index;

always @(posedge clk) begin
    if (!resetn) begin
        enable_o      <= 1'b0;
        mode_o        <= 2'b00;
        start_pulse_o <= 1'b0;
        clear_pulse_o <= 1'b0;
        data_in_o     <= 32'h0000_0000;
        irq_status_o  <= 2'b00;
    end else begin
        // W1P pulses are one clock wide by default.
        start_pulse_o <= 1'b0;
        clear_pulse_o <= 1'b0;

        // Hardware events set IRQ status.
        // Event set has priority over software clear in the same cycle.
        if (irq_done_event_i) begin
            irq_status_o[0] <= 1'b1;
        end else if (
            wr_en &&
            (wr_offset == REG_IRQ_STATUS) &&
            wr_strb[0] &&
            wr_data[0]
        ) begin
            irq_status_o[0] <= 1'b0;
        end

        if (irq_error_event_i) begin
            irq_status_o[1] <= 1'b1;
        end else if (
            wr_en &&
            (wr_offset == REG_IRQ_STATUS) &&
            wr_strb[0] &&
            wr_data[1]
        ) begin
            irq_status_o[1] <= 1'b0;
        end

        if (wr_en) begin
            case (wr_offset)
                REG_CONTROL: begin
                    if (wr_strb[0]) begin
                        enable_o <= wr_data[0];
                        mode_o   <= wr_data[2:1];
                    end
                end

                REG_COMMAND: begin
                    if (wr_strb[0]) begin
                        start_pulse_o <= wr_data[0];
                        clear_pulse_o <= wr_data[1];
                    end
                end

                REG_DATA_IN: begin
                    // Byte-enable write using WSTRB-equivalent strobes.
                    for (byte_index = 0; byte_index < 4; byte_index = byte_index + 1) begin
                        if (wr_strb[byte_index]) begin
                            data_in_o[byte_index*8 +: 8] <=
                                wr_data[byte_index*8 +: 8];
                        end
                    end
                end

                default: begin
                    // RO / reserved / unmapped writes have no effect.
                end
            endcase
        end
    end
end

always @(*) begin
    case (rd_offset)
        REG_CONTROL: begin
            rd_data = {29'h0, mode_o, enable_o};
        end

        REG_STATUS: begin
            rd_data = {29'h0, error_i, done_i, busy_i};
        end

        REG_COMMAND: begin
            // W1P command register has no retained state.
            rd_data = 32'h0000_0000;
        end

        REG_IRQ_STATUS: begin
            rd_data = {30'h0, irq_status_o};
        end

        REG_DATA_IN: begin
            rd_data = data_in_o;
        end

        REG_DATA_OUT: begin
            rd_data = data_out_i;
        end

        REG_VERSION: begin
            rd_data = VERSION_VALUE;
        end

        REG_ID: begin
            rd_data = ID_VALUE;
        end

        default: begin
            rd_data = 32'h0000_0000;
        end
    endcase
end

endmodule

어댑터의 주소 폭은 기본 32비트이고 실제 레지스터 선택에는 하위 8비트만 사용됩니다. bank는 AXI 핸드셰이크를 직접 처리하지 않고 wr_en과 wr_offset/wr_data/wr_strb를 사용합니다. 읽기는 rd_offset에 따른 조합 rd_data이며 어댑터가 AR 수락 시 값을 저장합니다.

구조도 읽기 · 버스 처리와 레지스터 의미를 분리한다

왼쪽 어댑터는 AW·W를 각각 저장하고 둘이 준비되면 wr_en·offset·data·strb를 만듭니다. 오른쪽 bank는 이 단순 인터페이스로 레지스터를 갱신합니다. 따라서 bank는 AW가 먼저 왔는지 알 필요가 없습니다. 두 모듈은 TB 아래 형제 인스턴스 dut·bank이며 bank가 dut의 자식은 아닙니다.

읽기 bank 출력은 주소에 즉시 반응하는 조합 경로지만, 버스의 RDATA는 AR 수락 에지에 별도 레지스터로 잡힙니다. 이 차이가 응답 대기 중 다른 주소를 제시해도 RDATA가 유지되는 이유입니다.

표의 commit은 해당 상승 에지에서 wr_en을 bank가 샘플링하는 사건이며 응답은 에지 이후 관찰됩니다. E2의 두 번째 수락 시점은 설명을 위한 예시입니다. TB는 하강 에지에 입력을 변경하며 모니터는 상승 에지의 핸드셰이크를 집계합니다.

판서 · AW와 W가 동시에 와도 쓰기는 다음 에지다

10ns 주기의 E0에서 AW/W가 모두 수락되면 에지 전 aw_stored·w_stored는0입니다. E0의 NBA 갱신 후 둘이1이 되어 wr_en이 올라가고, E1에서 bank가 이를 샘플링하여 저장합니다. E1 뒤 BVALID1이 보입니다. E0에서 버스 수락과 bank 쓰기가 동시에 일어난다고 읽으면 한 클록을 놓칩니다.

BREADY0에서 BVALID1·BRESP00을 유지해야 하며, 이 구현은 다음 AW/W의 ready도0으로 막습니다. 응답을 소비한 에지 뒤에야 ready가 복귀하므로 한 에지에 이전 B 완료와 새 AW 수락을 겹치는 처리량 최적화는 없습니다. 읽기와 쓰기는 독립적으로 각각 한 미결 거래를 허용합니다.

WSTRB(라이트 스트로브, 바이트 쓰기 활성 신호)가 0인 바이트는 기존 값이 유지됩니다. 0000은 레지스터 변화가 없어도 이 어댑터에서는 정상 쓰기 거래와 OKAY 응답을 생성합니다. 미매핑 쓰기와 RO 쓰기는 무시되며 미매핑 읽기는 0, 응답은 OKAY입니다. 이는 이 구현의 정책이지 모든 AXI 슬레이브의 일반 규칙이 아닙니다. 주소 0x110은 하위 8비트 0x10으로 해석됩니다. 상위 주소 디코딩은 외부 시스템에서 담당해야 합니다.

수치 계산 · WSTRB는 비트가 아니라 바이트를 선택한다

기존11223344에 새AABBCCDD·WSTRB0101을 쓰면 byte0의44가DD, byte2의22가BB로 바뀌어11BB33DD입니다. byte1의33과 byte3의11은 보존됩니다. byte_index*8 +: 8은 시작0·8·16·24에서 각각8비트를 고르는 구문입니다.

CONTROL의5=2진101은 enable=1, mode=10입니다. WSTRB0000도 버스 거래는 수락·commit·OKAY 응답을 만들지만 데이터는 바뀌지 않습니다. 미매핑 주소를 오류 응답으로 만드는 회로도 가능하나 현재 스냅샷은 무시/읽기0 정책입니다. 주소110과10의 별칭은 하위8비트만 쓰기 때문에 발생합니다.

commit 7회 중 마지막 B 응답은 리셋으로 취소됩니다. AR 13회 중 마지막 리셋 전 읽기의 R 응답도 취소됩니다. 따라서 완료된 B 6회와 R 12회로 총 18개 checks가 됩니다. 카운터는 테스트 전체의 관찰 기록이므로 DUT 리셋에서 초기화하지 않습니다.

전체 코드 · 계수마다 사건의 단위가 다르다

마지막 AW/W 수락과 commit은 각각7회지만 B 완료는6회입니다. AR은13회, R 완료는12회이며 각각 한 응답을 리셋으로 취소했습니다. checks18은 finish_b6회+정상 read_expect12회입니다. 이 계수들은 회로의 총 비교 조건 수와 같지 않습니다.

모니터는 commit 검사를 그 에지의 새 수락 집계보다 먼저 합니다. 이전에 수락한 주소·데이터로 쓰기가 이루어져야 한다는 어댑터의 한 클록 계약과 맞습니다. TB 계수는 resetn0 동안 증가를 멈추지만 초기화하지 않아 리셋 전후 전체 실행을 합산합니다.
